On a GitHub binary file page, choose **Download raw file**. Source is also directly available in the repository root. See the [main README](../README.md) and installation guides before running.

Windows packages are unsigned development builds and native Windows acceptance remains outstanding. These preserved Windows packages contain their original 3.0.0 documentation; the repository and source ZIP contain the updated GitHub setup guides. No runtime credentials, user databases or private network records are distributed.

Downloads are stored here because the connected publication interface supports repository files but does not expose release-asset uploads.

The Windows binary files are not yet uploaded. The manifest retains their expected checksums from the supplied packages. Run `sha256sum --ignore-missing -c SHA256SUMS.txt` to check only files present in this folder.
